# نور الصلاة | Noor Salah

تطبيق أندرويد عربي لمواقيت الصلاة والقبلة والقرآن الكريم والأذكار، بهوية زمردية وذهبية، مع دعم العمل دون اتصال في الأجزاء التي تتوفر لها بيانات محلية.

## المزايا

- **مواقيت الصلاة:** دعم الأردن أولاً، مع اختيار المدينة أو الموقع، ضبط الفروق بالدقائق، وعرض الصلاة القادمة والعد التنازلي.
- **تنبيهات الصلاة:** تحكم مستقل لكل صلاة، إعادة الجدولة بعد إعادة تشغيل الهاتف أو تغيير الوقت والمنطقة الزمنية، وخيارات الأذان الكامل والقصير والتنبيه النظامي.
- **صوت الأذان:** تسجيلان مدمجان بترخيص CC0، مع إمكانية استيراد ملف صوتي من الجهاز ومعاينته وضبط مستوى تشغيله.
- **القبلة:** بوصلة مستشعرات الهاتف، تصحيح الانحراف المغناطيسي، ومراعاة دوران الشاشة وحالة دقة المستشعر.
- **القرآن الكريم:** نص عثماني من Tanzil الإصدار 1.1 مدمج دون تعديل، 114 سورة و6,236 آية، بحث عربي، فهرس الأجزاء والصفحات، علامات مرجعية، وحفظ موضع القراءة وحجم الخط.
- **التلاوات:** بث السورة كاملة من Islamic Network / Al Quran Cloud، مع اختيار القارئ والتكرار. يتطلب الاتصال بالإنترنت.
- **الأذكار والمسبحة:** أقسام تفاعلية، عداد وأهداف قابلة للتخصيص، حفظ التقدم محلياً.
- **التقويم الهجري:** بيانات شهرية من المصدر عند توفرها، مع تقويم أم القرى المحلي على Android 7.0/API 24 وما بعده عند غياب الاتصال.
- **ويدجت الشاشة الرئيسية** وإعدادات المظهر والتنبيهات والموقع.

## الدقة والمصادر

- مواقيت الأردن المتصلة تُجلب من خدمة [prayertime.si](https://prayertime.si/)، وهي خدمة مستقلة تنسب طريقة الحساب إلى وزارة الأوقاف الأردنية وتذكر مطابقتها للجدول المنشور. قد يختلف وقت المسجد دقيقة أو دقيقتين؛ إعلان وزارة الأوقاف والمسجد المحلي هو المرجع العملي.
- عند إيقاف مصدر الإنترنت أو انقطاعه، يستخدم التطبيق الحساب المحلي التقديري. لا يُعرض هذا البديل على أنه جدول رسمي.
- نص القرآن مأخوذ من [Tanzil](https://tanzil.net/) كما ورد، مع حفظ الإسناد والترخيص داخل التطبيق. لا يغيّر التطبيق نص الآيات.
- التلاوات الصوتية تُبث من [Al Quran Cloud](https://alquran.cloud/terms-and-conditions). حقوق التسجيلات تبقى للقراء أو أصحاب الحقوق، والبث يخضع لشروط المصدر.
- تسجيلات الأذان المدمجة وملفات المصدر موثقة في المسار: app/src/main/assets/ADHAN_ATTRIBUTION.txt.

## الخصوصية

- لا يحتاج التطبيق إلى حساب.
- عند تفعيل مصدر المواقيت المتصل، يرسل التطبيق رمز المدينة للمدن المدعومة، أو إحداثيات مقربة عند الحاجة؛ يمكن إيقاف هذا المصدر واستخدام الحساب المحلي.
- ملف الأذان الذي يستورده المستخدم يبقى على الجهاز ولا يُرفع إلى الخدمة.
- العلامات المرجعية والإعدادات والتقدم في الأذكار تُحفظ محلياً.

## البناء والاختبارات

يتطلب المشروع Android SDK وJDK 17.

    ./gradlew testDebugUnitTest
    ./gradlew assembleDebug

تُبنى نسخة Release الموقعة عبر GitHub Actions باستخدام إعداد التوقيع المحفوظ للمستودع. لا تغيّر applicationId أو مفتاح التوقيع عند إصدار تحديثات للمستخدمين.

## متطلبات النظام

- الحد الأدنى: Android 6.0 / API 23.
- الهدف الحالي: Android API 36.
- يلزم منح إذن الإشعارات والمنبهات الدقيقة حتى تعمل تنبيهات الصلاة وفق إعدادات الجهاز.
- قد تقيّد بعض الأجهزة تشغيل التنبيهات في الخلفية بسبب إعدادات توفير البطارية؛ راجع إعدادات البطارية إذا تأخرت التنبيهات.

## ملاحظات

هذا المشروع قيد التطوير والاختبار على أجهزة فعلية. نجاح بناء APK لا يغني عن اختبار التنبيهات والصوت والحساسات على الهاتف المستهدف. التقويم المحلي قد يختلف عن ثبوت الهلال، والمواقيت الحسابية قد تختلف عن إعلان المسجد.
